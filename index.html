🚀 Quick Start

📋 Setup Instructions:

  1. Get a free API key from ai.google.dev
  2. Click "⚙️ Configure Settings" above
  3. Paste your Gemini API key in the settings
  4. Click "💬 Start Chat" to begin
  5. Type your questions and press Enter
🔐 Security: Your API key is stored securely in your browser and never sent anywhere except to Google's Gemini API.
