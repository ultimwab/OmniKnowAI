🚀 Quick Start

  1. Get API Key: Visit ai.google.dev
  2. Clone Repository:
    git clone https://github.com/ultimwab/OmniKnowAI.git
  3. Install Dependencies:
    pip install -r requirements.txt
  4. Configure .env:
    cp .env.example .env
    GEMINI_API_KEY=your_key_here
  5. Run OKA:
    python oka_assistant.py
